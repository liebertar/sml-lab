# 실험 규칙

1. 실험 하나 = 디렉토리 하나. 번호 접두사로 순서를 남긴다 (`01-minrf-web`).
2. `README.md`에 반드시 적는다: 목표, 참고한 원본(링크·커밋·라이선스), 실행 방법, 결과 표, 배운 것.
3. 원본 코드는 `third_party/`에 subtree로 두고 여기서는 import만 한다. 원본 파일을 직접 고치지 않는다.
4. 모델·데이터·산출물은 커밋하지 않는다. 결과는 숫자 표와 작은 이미지로만 남긴다.
5. 라이선스 없는 원본은 가져오지 않는다. 구조를 보고 다시 쓴다.

새 실험은 `_template/`를 복사해서 시작한다.
